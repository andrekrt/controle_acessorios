# Controle de Bijuterias

Sistema simples em PHP e MySQL para controle de produtos, entradas de estoque, vendas, pagamentos e lucro.

## Funcionalidades

- Cadastro de produtos
- Entrada de estoque
- Controle de estoque atual
- Registro de vendas
- Controle de vendas pagas e pendentes
- Cálculo de lucro recebido e lucro a receber
- Listagens com pesquisa, ordenação e paginação usando DataTables
- Select pesquisável com Select2
- Alertas com SweetAlert2
- Ícones com Font Awesome
- Layout responsivo para mobile

## Tecnologias usadas

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- jQuery
- DataTables
- Select2
- SweetAlert2
- Font Awesome
